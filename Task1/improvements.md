### Возможные улучшения

#### Данные для защиты

| Данные | Способы защиты |
|--------|----------------|
| Иные ПДн пациентов (за исключением медицинских) | Разграничение доступа (RBAC), шифрование, тегирование, аудит доступа |
| ПДн пациентов медицинского характера | Разграничение доступа (ABAC), обезличивание (если возможно), шифрование, тегирование, аудит доступа |
| Финансовые данные | Разграничение доступа (RBAC), обезличивание (если возможно), шифрование, тегирование, аудит доступа |
| Прочие данные о деятельности компании | Разграничение доступа (RBAC), шифрование, тегирование, аудит доступа |

#### Тегирование данных

Выбор системы для тегирования достаточно сложен и определяется многими факторами, в т.ч. возможностью легальной покупки у поставщика. В приоритете использование Collibri, однако также стоит рассмотреть Apache Atlas несмотря на возможные сложности при интеграции. 
Используемые теги:
- PII для конфиденциальных данных клиентов (за исключением медицинских)
- PHI для конфиденциальных медицинских данных
- FIN для конфиденциальных данных об оплате
- CNF для прочих конфиденциальных данных
