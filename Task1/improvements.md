### Возможные улучшения

#### Данные для защиты

| Данные | Способы защиты |
|--------|----------------|
| Иные ПДн пациентов (за исключением медицинских) | Разграничение доступа (RBAC), шифрование при передаче, тегирование, аудит доступа |
| ПДн пациентов медицинского характера | Разграничение доступа (ABAC), обезличивание (если возможно), шифрование при передаче, тегирование, аудит доступа |
| Финансовые данные | Разграничение доступа (RBAC), обезличивание (если возможно), шифрование при передаче, тегирование, аудит доступа |
| Прочие данные о деятельности компании | Разграничение доступа (RBAC), шифрование при передаче, тегирование, аудит доступа |

#### Тегирование данных

Для маркировки возможно внедрить инструменты, которые позволяют автоматически помечать данные при их обнаружении или создании.
Informatica Data Catalog автоматизирует маркировку на основе правил профилирования и классификации данных.
Microsoft Azure Information Protection применяет метки к документам и электронным письмам в Office 365.
С учетом планируемых доработок в большей части предполагается собственная реализация тегирования.
Используемые теги:
- PII для конфиденциальных данных клиентов (за исключением медицинских)
- PHI для конфиденциальных медицинских данных
- FIN для конфиденциальных данных об оплате
- CNF для прочих конфиденциальных данных
